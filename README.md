## <img src="https://media.giphy.com/media/iY8CRBdQXODJSCERIr/giphy.gif" width="28"> About

I'm a **Software Engineer** and **Computer Science undergraduate at Oregon State University** (GPA 3.9, Dean's List) who builds production systems end-to-end — from PostgreSQL data models and secure backend APIs to server-rendered React frontends and deployed machine-learning pipelines.

- **Software engineering first.** I design append-only time-series data models, transactional roll-up hooks, idempotent scheduled jobs, and REST APIs that hold up under real load — currently across two engineering internships at **Zyp** (cross-border payments fintech) and **Next League** (sports-technology consulting).
- **AI/ML in the field, not the notebook.** At **Warren Lab (OSU)** I ship computer-vision pipelines to edge hardware — YOLOv8 + ResNet + Kalman tracking on Raspberry Pi, sustaining 20 FPS across 1.5M+ frames at 99.5% mAP@50. Second author on a Jul 2026 bioRxiv preprint.
- **Full-stack by default.** Next.js 16 / React 19 on the server/client boundary, Deno Edge Functions, Flask & FastAPI, WebSockets and SSE — comfortable owning a feature from schema to UI.
- **Product engineering mindset.** I care about security posture (RLS, `SECURITY DEFINER`, authorization audits), human-in-the-loop AI workflows, and shipping things people actually use — PyPI packages, hackathon-winning demos, hardware-to-web systems.

> **Open To:** Software Engineering internships & new-grad roles (2026–2028) • AI/ML engineering • Full-stack product teams • Open-source collaboration

| Facet | Detail |
| :--- | :--- |
| **Stack** | Python, FastAPI, WebSocket, SSH |
| **Scale** | Persistent labeling sessions with staged, undoable changes |
| **Performance** | Keyboard-driven workflow for high-throughput annotation |
| **Security** | Remote SSH support with session persistence |
| **Impact** | ✅ **Published on PyPI (2026)** — `pip install swiftlabel` |

Built to eliminate the friction of manual dataset labeling: a fast local CLI with a WebSocket-backed UI, staged and reversible edits, and first-class remote SSH sessions so labeling can happen anywhere the data lives.
